# HabitWise privacy policy — publisher draft

**Effective date:** [PUBLISHER DATE]

HabitWise is designed to work without an account. Craving check-ins, optional health context, medication patterns, reflections, learned preferences, and settings are stored in an encrypted database on the user’s device.

HabitWise does not include advertising, third-party behavioral analytics, or remote telemetry. The publisher does not receive app-entered data through the version described by this policy.

The app may ask the operating system for notification permission when the user explicitly enables a local reminder. Reminder schedules are calculated and stored on the device. Turning reminders off cancels those schedules.

The user can export a JSON copy. Exported data is sent only to the destination the user selects through the operating-system share interface. That destination’s privacy practices then apply.

The user can delete all app data from Profile. This deletes the profile, history, learned weights, plan statistics, reflections, and settings from the app database.

HabitWise is a self-reflection and behavior-support tool. It is not emergency care, a diagnostic service, a medical device, or a substitute for a clinician. Optional health information is used only to adjust on-device questions and support options.
