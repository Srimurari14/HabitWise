# Archive manifest and exclusions

## Included

- Complete authored Flutter source, tests, assets, configuration, Android/iOS scaffolds, store drafts, documentation, lockfile, and generated Drift source.
- Complete authored legacy Electron/Node source, lockfile, detailed legacy `CLAUDE.md`, and medical-layer design proposal.
- Original project prompts from four relevant Codex attachments, renamed and indexed.
- Verified Android APK, original emulator package, installer scripts, and checksum records.
- Representative Home, Avatar, Signal Shift intro, and gameplay screenshots.
- AI-oriented root instructions, project memory, current state, continuation prompt, artwork provenance, research/validation status, and this manifest.

## Deliberately excluded

- `flutter_app/.dart_tool/` — regenerated by Flutter/Dart.
- `flutter_app/build/` — machine-specific build output totaling several gigabytes.
- `flutter_app/.idea/` and `habitwise.iml` — machine-specific IDE state.
- redundant/obsolete `flutter_app/dist/` artifacts — the verified current release is copied once under `release/`.
- `legacy_node_prototype/node_modules/` — regenerated with `npm install`; roughly hundreds of megabytes.
- empty source-workspace `.git/` and `.agents/` directories — contained no history or memory.
- user secure-storage keys, emulator databases, personal exports, Android SDK, Flutter SDK, Java runtime, and signing credentials — none belong in a transferable source handoff.

These exclusions do not remove authored project information. They avoid non-portable caches and secret/user-device material while keeping the archive practical to transfer.
